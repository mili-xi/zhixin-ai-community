# Security and privacy

Do not submit secrets, browser profiles, production connection details, user records or screenshots containing personal data in public issues. Report a security concern privately to the repository owner via GitHub before publishing exploit details.

Configuration examples use reserved example domains and addresses. Generate your own signing key before packaging; keep the private key outside this repository. Update dependencies and review external platform terms before deployment.

This community repository starts with independent history. Automated scans reduce risk but do not guarantee the absence of all security defects. No claim of production certification is made.
